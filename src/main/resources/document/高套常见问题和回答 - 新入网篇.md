# 高套常见问题和回答 - 新入网篇
#### 新入网宽带的口径是什么？
如果是公私融合：1、取当月竣工的公私融合销售品，销售品实列内含宽带产品的当月入网号码；公私融合优先级最高，高套类型归到新入网宽带
ZH0002-223-1-3 政企公私融合升级低消包-1000M
ZH0002-223-1-2 政企公私融合升级低消包-300M
ZH0002-223-1-1 政企公私融合升级低消包-100M
ZH0002-223-1-4 政企公私融合升级低消包-2000M
2、在原套餐积分基础上，当移动主卡当月有手机合约则加上手机合约销售品积分，再折算高套 
3、客户净增积分大于等于0
如果是其它宽带：1、含宽带的融合套餐或宽带单产品，套餐内所有号码均为当月入网，取套餐到达积分；
2、如套餐内有移动主卡且当月有手机合约销售品，则加上手机合约销售品积分，再判断套餐积分大于等于59并折算高套 
3、客户净增积分大于等于0

#### 新入网融合专线的口径是什么？
1、指定融合销售品、专线、对应移动主卡三者均为当月入网，取其移动主卡对应的套餐积分；
2、限制专线产品：48,57,600039000
3、融合专线销售品CPC配置：ATTR_ID='500067201'
4、如移动主卡当月有手机合约销售品，则加上手机合约销售品积分，再判断套餐积分大于等于59并折算高套 
5、客户净增积分大于等于0

#### 单品专线的口径是什么？
1、单品专线产品，且号码到达积分大于等于59；
2、剔除S转O：即新入网组网专线产品（600019010 OTN精品专线），当其同一产权客户名下有SDH/MSTP产品且状态为停机或正常（600031024 SDH电路、218 数字电路（端）、219 数字电路、600031025 MSTP电路）时，且电路级别 （id=156）为L001 本地电路，不统计为新入网单品专线；
3、专线新入网由‘近32天入网’修改为‘近6个月入网第1次产生非0到达积分’；
4、客户净增积分大于等于0
