# 高套常见问题和回答 - 存量篇
#### 存量专线升级的口径是什么？
1、锁定专线产品：IP城域网（57）、LAN专线（52）、天翼宽带专线（48）、商务专线（600039000）、SD-WAN（600041011,600041009）；
2、判断存量由‘32天前入网’修改为‘非新入网’；新入网定义近6个月入网第1次产生非0到达积分；
3、仅按客户汇总专线产品积分，不再统计标品积分，标品分别移到强合约和政企团购统计。 
4、含当月物理拆机积分；
5、客户净增积分大于等于0；

#### 改套餐的口径是什么？
1、按销售品取，改套餐销售品CPC配置：attr_id = '500075371' --5G主套餐 
2、套餐级移宽融合
3、非纯新套餐
4、产品限制取移动主卡和宽带（含互联网专线）
5、原套餐净增积分大于等于0，如移动主卡当月有手机合约销售品，则加上手机合约销售品积分再判断套餐积分大于等20并折算高套；
6、客户净增积分大于等于0

#### 强合约-政企N标品的口径是什么？
如政企全光组网、视联网（政企渠道），增加CPC加配置后生效，按强合约统计规则。

#### 强合约-金融合约续约 的口径是什么？

1、接续销售品CPC配置(NEW)：金融合约，标签编码500075353，且标签值为3；
2、被接续销售品CPC配置(OLD)：终端合约，标签编码500040231，且标签值为('2','3','4','5','6','10','12','14','15','16','17')
3、统计新旧两个销售品积分差值（新续约积分-旧合约积分），按存量强合约统一标准折算高套；
4、剔除销售品名字里面含有“加装版”’字眼的；
5、限制移动主副卡；
6、原销售品的失效时间和新销售品的竣工时间差为（30,120]天，如若还存在一个号码对应多个销售品的情况，则按时间取最近一条；
7、剔除与当月存量高套升级重叠的号码清单；
8、客户净增积分大于等于0

#### 强合约-其他强合约的口径是什么？

1、按销售品统计，attr_id = '500075353' and default_value in (1,2,3)) --强合约 
2、非纯新套餐;
3、原套餐净增积分大于等于0，如移动主卡当月有手机合约销售品，则加上手机合约销售品积分再判断套餐积分大于等20并折算高套；
4、增加限制条件：号码对应的客户名下指定11N产品当月到达积分减上月到达积分大于等于0 ；指定产品包含：互联网专线、政企全光组网（600026012智能组网（商企版）、600047024企业全光组网（FTTR-B））、N标品（云电脑政企版（600023006云桌面-服务、600024003云桌面-计算单元）、视联网（600030020天翼云眼、600025002）、天翼安全大脑（500000302）、AONE（600002000 省内云产品）、云主机（2337 省内云主机（标准）、2338 省内云主机（个性化））。 
5、存量强合约剔除话补：剔除未改套餐且通过叠加话补强合约+增值包实现升级高套的销售品；
6、客户净增积分大于等于0
